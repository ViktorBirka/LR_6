# Лабораторна робота №7

`task1.js` оголошує змінні типів string, number, boolean, а також значення null і undefined та виводить їх у консоль.

`task2.js` визначає повноліття за умовою `age >= 18`. Вік 18 років використано як навчальний приклад.

Запуск із кореня проєкту:

```sh
node jsBasics/task1.js
node jsBasics/task2.js
```

Для перегляду в браузері відкрийте `jsBasics/console.html`. Сторінка запускає обидва файли та показує їхній фактичний вивід console.log. Ці повідомлення також доступні в консолі розробника.

Фактичний результат запуску в Node.js збережено у `console-output.txt`.

Для здачі додайте посилання на пул-реквест і скриншот виконання програми. Скриншот можна зробити після запуску команд вище або після відкриття `console.html` та консолі розробника браузера.
